# 🍎 Orchard Gacha

A browser-based character collection and gacha game built for Aiden by Switch.

## 🌟 Features
- **20 Unique Fruit Heroes**: From Pippin the Apple Archer to the celestial Nova the Starfruit Sovereign.
- **Fair Gacha Rates**:
  - Common: 70%
  - Rare: 29%
  - Legendary: 1%
- **Interactive Apple Tree**: Tap hanging golden apples or shake the whole tree to harvest Apple Coins.
- **Orchard Expeditions**: Send heroes into the grove to discover treasures and fruit gems.
- **Audio & Visual Effects**: Web Audio synthesizer chimes, card reveal flips, glowing rarity frames, and confetti celebration.
- **Cloudflare Zero Trust Access**: Secured for Aiden and authorized BeerCanLabs operators at `https://orchard-gacha.beercanlabs.ai`.
